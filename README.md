# The Zero Credit Project — Coming Soon

This repository now includes a static landing page for GitHub Pages. The original Shopify theme source is preserved in `shopify-theme/` and is not used by the Pages site.

## Deploy with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your publishing branch (usually `main`) and folder **/(root)**.
5. Click **Save** and wait for the Pages deployment to finish.

Make sure `index.html` is in the repository root (the same level as this README), not inside another nested project folder.

## Files

- `index.html` — landing page markup
- `assets/style.css` — responsive styling
- `assets/script.js` — tiny progressive enhancement
- `shopify-theme/` — preserved original Shopify Liquid theme source

This is a static coming-soon page. Shopify cart, checkout, product catalogue, newsletter submission, and other Shopify-only features are intentionally not active here.
